This project focuses on sentiment analysis of women's clothing reviews from an e-commerce dataset. It includes cleaning and preprocessing text data, exploratory data analysis (EDA), and building machine learning models for sentiment classification. The preprocessing involves removing irrelevant columns, handling missing values, and transforming text data using lemmatization and TF-IDF vectorization. The dataset is labeled into three sentiment categories (Positive, Neutral, and Negative) based on the ratings.

Exploratory analysis includes visualizations like sentiment distribution, review length histograms, and word clouds for different sentiment classes. Machine learning models such as Logistic Regression, Support Vector Machine (SVM), Random Forest, and XGBoost are trained to classify sentiments. Hyperparameter tuning is performed using `RandomizedSearchCV`, and the models are evaluated based on metrics like accuracy, precision, recall, and F1-score. 

The project is implemented in Python using libraries such as pandas, numpy, scikit-learn, matplotlib, seaborn, and nltk. To reproduce the results, clone the repository, install the required libraries, and execute the provided script. This project showcases the application of machine learning techniques to text data and highlights the importance of preprocessing and model evaluation in sentiment analysis.
